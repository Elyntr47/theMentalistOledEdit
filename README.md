# The Mentalist — OLED Animation

[English](README.md) · [Türkçe](README.tr.md)

A 200-frame pixel-art animation of *The Mentalist* (Patrick Jane) playing on a
**128×64 SSD1306 OLED** display, driven by an Arduino-compatible board over I²C.

## Features

- 200 frames, ~7.4 fps (135 ms per frame), ~27 s per loop
- Frame data stored in `PROGMEM` and pushed straight to the display — no SD card,
  no frame decoding at runtime
- Non-blocking frame timing based on `millis()`, so the loop stays responsive
- Serial debug output at 115200 baud

## Hardware

| Part | Details |
|------|---------|
| Display | 0.96" SSD1306 OLED, 128×64, I²C, address `0x3C` |
| MCU | **Any board with ≥ 256 KB flash** — ESP32 / ESP8266 / RP2040 recommended |
| Wiring | OLED `VCC` → `3V3`, `GND` → `GND`, `SDA` → `SDA`, `SCL` → `SCL` |

### ⚠️ Not for classic AVR boards

The 200 frames × 1024 bytes = **~200 KB** of frame data. An ATmega328P
(Uno / Nano / Pro Mini) only has 32 KB of flash, so this sketch **will not
compile or run on an Uno or Nano**. Use an ESP32 (or another board with enough
flash), or shorten the animation to ~25 frames to fit an AVR.

Most 128×64 SSD1306 modules work on 3.3 V only — power the display from `3V3`,
not `5V`, unless your module explicitly supports 5 V.

## Libraries

Install through the Arduino IDE library manager:

- [Adafruit SSD1306](https://github.com/adafruit/Adafruit_SSD1306)
- [Adafruit GFX Library](https://github.com/adafruit/Adafruit-GFX-Library)
- [Adafruit BusIO](https://github.com/adafruit/Adafruit_BusIO) (dependency)

## Usage

1. Open `theMentalistOledEdit.ino` in the Arduino IDE.
2. Select your board and the right port.
3. Upload, then open the Serial Monitor at **115200 baud** to confirm the display
   was allocated successfully.
4. The animation starts looping automatically.

If the display stays blank, try address `0x3D` instead of `0x3C`, and double-check
SDA/SCL — on an ESP32 the defaults are `GPIO 21` (SDA) and `GPIO 22` (SCL).

## Configuration

```cpp
#define SCREEN_WIDTH  128
#define SCREEN_HEIGHT 64
#define OLED_RESET    -1
#define SCREEN_ADDR   0x3C
```

Frame timing and length:

```cpp
const uint8_t numFrames = 200;

if (millis() - lastMs >= 135) {   // lower = faster
  ...
}
```

To play only part of the animation, drop unused frames and lower `numFrames`.
